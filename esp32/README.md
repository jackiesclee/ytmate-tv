# 跳跳（ESP32-S3-Touch-AMOLED-1.8 V2）韌體

小智開源韌體（[78/xiaozhi-esp32](https://github.com/78/xiaozhi-esp32)，版本見 `XIAOZHI_VERSION`）＋ YTmate 頻道播放。
保留「你好小智」語音助理與小智 MCP 接入點（語音遙控電視）；另外加上：

## v2：頻道播放終端（只播聲音）
- 跳跳跟電視一樣出現在 YTmate **手機遙控頁**的裝置清單（🦘 跳跳）：選頻道／影片 → 在跳跳播；暫停、繼續、上一支／下一支、快轉倒退、音量。
- **語音**：對小智說「在跳跳上播最新的海峽早安新聞」「跳跳暫停」「下一個」。
- **螢幕**：片名、頻道、第幾支／共幾支、播放進度。
- **BOOT 按鍵**：單擊＝暫停／繼續；雙擊＝下一支；長按＝停止播放（沒在播時長按＝顯示狀態，10 秒內再長按一次＝重新配對）。
- **續播**：每 15 秒把播放位置回報給伺服器，跟電視／手機共用「上次看到哪裡」；播完一份清單會自動接「稍後播放」的待播清單。
- **小智打斷**：播放中說「你好小智」會暫停節目；對話結束約 1.5 秒後自動從剛才的位置接著播（在對話中說「暫停」就不會自動接著播）。
- 伺服器把 mp3（沒有 mp3 就用影片的聲音）轉成 Ogg/Opus（單聲道 24 kHz、32 kbps），跳跳用小智內建的通知播放器串流播放；
  第一次播邊轉邊傳，之後暫停／快轉直接從轉好的檔案找位置，馬上開始。
- 喇叭很小，適合新聞、談話、Podcast。
- 播放期間 Wi-Fi 關掉省電模式（不然每次連線要好幾秒），停止後恢復。
- 不會被小智官方韌體自動更新蓋掉（YTmate 自己發新版）。
- **錄音功能已移除**（v1.0.x 偶爾在停止錄音後黑屏）；錄音請用 YTmate 手機 App。

## 第一次用／從 v1 升級
- 燒好後長按 BOOT：螢幕顯示 6 位數配對碼，到 YTmate 網頁「📺 電視配對」頁輸入。
- **從 v1（錄音版）升級**：舊的配對還能用（同一種裝置 kind=esp32）。如果螢幕說「被當成電視或錄音裝置」，到配對頁取消「跳跳」再重新配對。

## 編譯與燒錄
- 推送 `esp32/` 底下的檔案 → GitHub Actions（`.github/workflows/esp32.yml`）用 `espressif/idf:v6.1` 編譯 → Releases「tiaotiao-v2.0.N」。
- 燒錄：Chrome／Edge 打開 https://espressif.github.io/esptool-js/ → Connect →「Flash Address」`0x0` → 選 `TiaoTiao-v2.0.N-merged.bin` → Program。
- 伺服器網址：預設 `https://music.iucat.net`；可在 repo Variables 設 `YTMATE_BASE_URL` 覆寫。

## 檔案
- `ytmate/ytmate.cc/.h`：配對、遙控長輪詢（`/api/remote/poll`）、播放清單、播放控制、狀態回報、螢幕提示、MCP 工具（self.ytmate.player_status／pause／next）。
- `apply_patch.py`：修改小智原始碼（Application 加「播放網址／停止／播放編號」三個方法＋播放進度與播完通知、節目不播提示音、BOOT 單擊／雙擊／長按、省電判斷、不自動裝官方韌體）。小智改版對不上時會明確失敗。
- 串流網址帶簽章（裝置＋影片＋到期時間，12 小時），因為小智的播放器不能帶金鑰標頭；取消配對後立刻失效。
