# YTmate TV 📺

YTmate 的**小米電視／Android TV 用戶端**（APK）。打開就自動登入 `https://music.iucat.net`，用遙控器選頻道、播放影片或音樂。

<img src="brand/banner_1280x720.png" width="480" alt="YTmate TV">

## 下載與安裝

1. 到這個 repo 的 **Releases**，下載最新的 `YTmateTV-v1.x.N.apk`（2026-10-17 起是 v1.1.x）。每次推送到 `main` 都會自動編譯一版。
2. 把 APK 拷到 USB 隨身碟，插上電視，用「檔案管理」打開並安裝。
   - 第一次安裝時，電視會要求允許「安裝未知來源應用」：設定 → 帳號與安全 → 允許安裝未知來源應用，各機型的位置可能略有不同。
3. 之後出新版，直接安裝新的 APK 就會覆蓋舊版，不用先移除，配對也會保留。

## 第一次使用：配對（自動登入）

1. 在電視上打開 YTmate，畫面會顯示 **6 位數配對碼** 和 **QR code**。
2. 用**已登入 YTmate 的手機**掃描 QR code，或打開 `https://music.iucat.net/pair` 輸入配對碼。
3. 按「允許這台電視」，電視就會自動登入。之後每次打開都直接進首頁。

> APK 裡**沒有密碼**。每台電視都有自己的裝置金鑰，伺服器只存金鑰的雜湊值。
> 不用的電視可以在手機的 `/pair` 頁面按「取消配對」，那台電視會立刻登出。

## 遙控器操作

| 畫面 | 按鍵 | 動作 |
|---|---|---|
| 首頁／頻道頁 | 上下左右 | 移動選取 |
| | 確認 | 開啟頻道／播放 |
| | **長按確認**（v1.1.2） | 影片卡片：加入待播清單；頻道卡片：整個頻道加入；「📋 待播清單」那排：從清單刪除 |
| | 選單（≡） | 開／關設定 |
| | 返回 | 回上一層；在首頁連按兩次離開 |
| 播放中 | 確認 | 暫停／播放 |
| | **長按確認**（v1.1.2） | 打開「接下來播放」：上下選、確認＝播放、長按確認＝刪除、返回＝關閉 |
| | 左／右 | 倒轉／快轉 10 秒（按住不放會加速：30 秒、60 秒）；畫面下方顯示時間軸，放開後恢復播放就消失 |
| | 上 | 顯示控制列（上一支、下一支、字幕） |
| | 下 | 字幕開／關（會記住；再打開時回到上次的語言） |
| | 選單（≡） | 開／關控制列（右邊同時顯示這支影片的中文摘要；控制列右下角有「🎧 只聽聲音／🎬 看影片」） |
| | 頻道上／下、媒體鍵 | 上一支／下一支 |
| | 返回 | 收起控制列；再按一次回到頻道頁 |
| 快播完（右下角「5 秒後播放」） | 確認／返回 | 立刻播下一支／取消（停在這支的結尾） |
| 螢幕保護 | 任意鍵 | 回到原畫面 |

- 控制列沒操作 3.5 秒就自動收起（暫停中會一直顯示，方便看進度）。
- 回到頻道頁時，焦點停在最後播放的那一支。
- 記住看到哪裡（v1.1 起所有影片都記，音樂除外），下次從那裡繼續；進度也存在伺服器，手機網頁、其他電視接著看。
- 網路短暫斷線會自動重新連線（同一個時間點繼續），不會直接跳過。

## 設定（⚙ 或選單鍵）

按確認鍵切換。設定存在 App 裡，**一直記住**，直到你再改；取消配對也不會清掉。

| 設定 | 選項 | 說明 |
|---|---|---|
| 畫質 | **自動（最佳）**／480p 省流量 | 自動＝依這台電視的解碼能力播最好畫質。480p 任何電視都能選（包括 HyperOS 3.0）：有 480p 版就播 480p；還沒轉好時這次先播原檔，同時在背景轉檔。 |
| 字幕 | **英文優先**／中文優先／關閉 | 預設自動開字幕、英文優先（沒有英文就中文）。在播放器的字幕選單改的，也會記成新的設定。 |
| 播放暫存 | **自動**／關閉 | v1.1：依電視剩餘空間自動決定（最多 500MB，剩餘不到 1GB 不暫存）；另有「🧹 清除暫存」。 |

## 🩺 回報播放卡頓（2026-10-30）
- 播放時自動記錄：開始播放等了多久、播到一半緩衝多久、快轉／跳轉後等多久、播放錯誤；每 15 秒或離開播放畫面時送到伺服器（`/api/playback/report`）。
- 在 YTmate 網頁「🔄 YouTube 同步 Task」頁的「🩺 播放狀況」看：各台電視的卡頓次數、秒數，以及卡頓當下伺服器忙不忙，用來判斷是伺服器、網路還是電視本身。
- 只送播放統計（影片 ID、畫質、時間點、等待毫秒），不影響播放；送不出去就丟掉。

## 📱 手機遙控（v1.1，2026-10-17）

在手機的 YTmate 網頁打開 **🕹️ 遙控**（`/remote`），或在任何影片、頻道、節目按「📺 在電視播放」：

- 播放／暫停、快轉倒轉（或拖曳進度條）、上一支／下一支、字幕、480p、**音量**、停止；每個操作都會顯示「電視已執行」。
- **待播清單**：在手機排好幾支，電視播完目前的清單後接著播。
- **貼 YouTube 連結**：伺服器下載好就自動在電視播（或放進待播清單）。
- 新一集做好、同步到新影片時，電視右上角會提示 6 秒，不中斷播放。
- 運作方式：App 開著時**主動**向伺服器領指令（長輪詢），所以電視在家裡的內網、外面連不進來也沒關係。
  指令 2 分鐘內沒送到就自動作廢（網路恢復後不會突然自己播），同一個指令不會執行兩次。電視要開著 YTmate 才收得到。

## 首頁、播放暫存、螢幕保護（v1.1）

- **首頁一排一排**：大橫幅（最新節目，左右鍵切換）、繼續觀看、最新同步、我的節目、我的頻道。選到影片時上方顯示標題、看到哪裡、**AI 中文摘要**。
  卡片標「新」、看過的變淡、看一半的有進度條（首頁是伺服器頁面，舊版 App 也看得到）。
- **章節**：YouTube 影片有章節的話，時間軸上會標出分段點，快轉時顯示目前章節名稱。
- **播放時加速下載**：網路有餘力時往前多緩衝（最多 5 分鐘）；**播放暫存依電視剩餘空間自動決定**：上限＝min(500MB, 剩餘空間的 10%)，
  剩餘不到 1GB 就不暫存；滿了或空間變少會自動刪最舊的。目前這支緩衝夠了就先下載下一支的開頭，切換時秒開。設定頁可以看用量、關閉或清除。
- **螢幕保護**：YTmate 開著、5 分鐘沒按鍵也沒在播放 → 輪播最新節目封面和時間。也可以在電視設定的螢幕保護程式選「YTmate」
  （大陸版小米電視多半只能用小米自己的屏保，選不到也不影響）。

## v1.1.1（2026-10-17）：播放更順＋拿掉大黃框

- 播放器對播放暫存**只讀不寫**：正在播的影片不再整支寫進電視的儲存空間（舊電視的儲存晶片很慢）。
- 預先下載更保守：目前這支整支緩衝好、播放 15 秒以上才抓下一支的前 90 秒；一卡頓就停止預先下載。
- 回報卡頓統計（手機遙控頁顯示「這支卡了 N 次」）。
- 關掉系統焦點外框（小米電視上的大黃框）。

## v1.1.3（2026-10-18）：🎧 只聽聲音

- 播放中按選單鍵叫出控制列 →「🎧 只聽聲音」：影片改播 mp3（同一個位置接著播），畫面全黑；再按「🎬 看影片」切回來。首頁 ⚙ 設定也能切換。
- 整台電視一個設定，一直記住。字幕照樣顯示、可以開關和換語言。
- 10 秒沒按鍵把畫面亮度調到最低（電視允許的話）；按任何鍵恢復。LCD 電視黑畫面背光仍亮，真正關螢幕請用小米的「息屏聽」。
- 沒有 mp3 的影片照樣播影片；音樂不受影響。手機遙控頁顯示「🎧 只聽聲音」，手機也能送 `control: listen`。

## v1.1.2（2026-10-17）：在電視上管理待播清單（長按確認鍵）

- 首頁新增「📋 待播清單」一排：確認＝從這支開始播（前面的留著）、**長按確認＝刪除**、最後一張「清空」連按兩下。
- 一般影片卡片**長按確認＝加入待播清單**；頻道卡片長按＝整個頻道（可以播的影片）加入；已在清單的不會重複加。
- 已在待播清單的影片，卡片右上角有 📋 標記；選到影片時上方會顯示操作提示。
- 播放中**長按確認**打開「接下來播放」：列出這份清單接下來的影片＋待播清單，可以直接播、長按刪除；短按確認還是暫停。
- 長按判斷由 App 做（按住 0.6 秒以上，或遙控器送出「按住」的連發訊號），再告訴頁面 `window.tvOkKey('short'|'long')`；網頁核心本身收不到連發訊號。放開才決定短按，避免誤觸。

- 修正：登入過期時同時好幾個請求失敗，不會再跳到配對畫面（只重新登入一次）。
- E2E：Android 7.0／9 各 148 項全部通過。

## 不同電視播不同版本

- 2026-10-17：**小米電視（Xiaomi／MiTV／MiBox／Redmi）預設 480p 省流量**（伺服器電視頁判斷機型；在 ⚙ 自己選過畫質的照自己選的）。

- **新電視**（例如小米 HyperOS 3.0，晶片支援 AV1）：播原檔，畫質最好。
- **舊電視**（例如小米 L55MA-A，系統 2.10.x，解不了 AV1）：自動改播伺服器上的 480p 相容版（H.264），不會再「只有聲音」。
- **判斷方式**：App 回報這台電視能硬體解碼的格式，伺服器依此排出每支影片的播放順序。播放時如果仍發現畫面解不了，會自動換下一個版本，從同一個時間點繼續。
- **舊的網頁核心**（Chrome 80 以前）會自動開啟輕量模式，關掉背景模糊與動畫，避免卡頓。
- **查看這台電視的資訊**：⚙ 設定頁會顯示型號、Android 版本、網頁核心版本、可硬體解碼的格式。
- 想省流量或網路較慢，可以在設定頁把畫質改成「480p 省流量」。

## 架構

- **介面**：伺服器上的電視版頁面 `https://music.iucat.net/tv`，由全螢幕 WebView 顯示。改畫面只要更新伺服器，**不用重裝 App**。
- **播放**：原生 Media3 ExoPlayer，硬體解碼、遙控器原生支援，媒體請求會帶上登入 cookie。
- **登入**：裝置配對拿到長期裝置金鑰，存在 App 私有空間；每次開啟時 `POST /api/tv/login` 換成 session。
- **安全**：WebView 只允許開本服務的網域，其他網址一律擋掉。

```
app/src/main/java/net/iucat/ytmate/tv/
├── MainActivity.kt    # WebView 外殼、JS 橋接（window.YTmateTV：配對、播放、設定、自動重新登入、遙控結果、暫存）、硬體解碼偵測、返回／選單鍵、離線重試畫面
├── PlayerActivity.kt  # 原生播放器（清單播放、換版本、控制列、字幕、續播、斷線重連、MediaSession、遙控操作、下一支倒數、章節、摘要、提示、預先下載）
├── Remote.kt          # v1.1 手機遙控：長輪詢領指令、回報狀態、音量、看到哪裡存到伺服器
├── MediaCache.kt      # v1.1 播放暫存（依剩餘空間自動決定大小）
└── SaverService.kt    # v1.1 系統螢幕保護程式
e2e/                   # 自動測試：測試伺服器、測試影片、遙控器測試腳本、相容性檢查
brand/                 # 圖示與橫幅原始檔（SVG）
.github/workflows/build.yml  # 自動編譯＋發佈 Release
```

## 自動測試（E2E）

每次推送到 `main`，GitHub Actions 的「E2E 測試」會自動跑兩項測試：

1. **相容性檢查**：用 `e2e/compat_check.js` 確認電視頁面的 CSS 與 JavaScript 在 Android 7.0（Chrome 53）以上的網頁核心都能用。
2. **模擬器實測**：在 **Android 7.0** 與 **Android 9** 的電視模擬器上，安裝自動測試版 APK（`gradle :app:assembleE2e`，連到 `e2e/mock_server.py`），用 adb 送出真的遙控器按鍵：
   - 配對畫面 → 核准 → 自動登入
   - 首頁：卡片大小一致、16:9、每排 4 張、往下捲到最後一排、沒有橫向超出
   - 設定頁：裝置資訊
   - 播放三支顏色不同的測試影片（`e2e/media/`），截圖取色確認播的版本：
     - H.264 原檔 → 藍色
     - AV1（伺服器已知格式）→ 直接播 480p，綠色，而且不會去下載 AV1 原檔
     - AV1（伺服器不知道格式）→ App 偵測後自動改 480p，綠色
     - 純音樂
   - 每個媒體請求都帶登入 cookie
   - 字幕：預設自動開啟英文字幕；播放中按「下」關閉、再按打開（回到英文），而且會記住
   - 時間軸：按住「右」快轉 → 畫面下方出現時間軸、連續快轉 → 放開後恢復播放就消失；按「左」倒轉一樣；過程中控制列不會跑出來
   - 控制列：開始播放後自動收起；按「上」叫出控制列，移到「下一支」按確認，下一支開始播後自動收起；暫停時保持顯示，繼續播放後收起（這段測試打開動畫，跟真的電視一樣）
   - 回到頻道頁時，焦點停在最後播放的那一支
   - 續播：看到一半離開，再開同一支從上次的位置繼續
   - 設定：改成「480p 省流量」與「中文優先」→ 頻道改排 480p、H.264 影片改播 480p（綠色）、不下載原檔、字幕顯示中文
   - 選單鍵開關設定；登入過期時自動用裝置金鑰重新登入
   - 返回鍵、首頁連按兩次離開、重新開啟自動登入（設定仍記得）
   - v1.1 手機遙控（測試程式扮演手機）：播放（指定開始時間）、暫停／繼續、快轉＋章節名稱、音量、右上角提示、選單鍵顯示摘要、
     播放器開著時換清單、預先下載下一支、「5 秒後播放下一支」（取消／立即播）、播完接著播待播清單、停止、看到哪裡存到伺服器
   - v1.1 首頁一排一排：大橫幅左右切換、各排移動、選到影片顯示摘要、往上回到大橫幅、按確認播放；螢幕保護；系統螢幕保護程式；設定頁播放暫存

報告、截圖和 logcat 發佈在 Releases 的 `e2e-api24`、`e2e-api28`（預覽版，不影響正式 APK）。

> `e2e/www/` 是伺服器 `assets/` 裡電視頁面的副本；伺服器的電視頁面有改的話，這裡要同步更新。

## 自己編譯（選用）

- 需要 JDK 17、Android SDK（API 34）和 Gradle 8.9，執行 `gradle :app:assembleRelease`。
- 伺服器網址可以用環境變數 `YTMATE_BASE_URL` 覆寫，預設是 `https://music.iucat.net`。
- 正式簽章用 `YTMATE_KEYSTORE`、`YTMATE_KEYSTORE_PASSWORD`、`YTMATE_KEY_ALIAS`、`YTMATE_KEY_PASSWORD` 這幾個環境變數提供（GitHub Actions 讀 repo Secrets）。

最低支援 Android 7.0（API 24）。
