# YTmate 手機／平板版（小米手機、紅米手機、小米平板）

Android 7.0 以上。介面是伺服器上的手機版頁面 `/m`（WebView，改介面不用重裝 App），播放和錄音用原生功能。

## 安裝
1. 用手機瀏覽器下載 Releases 的 `YTmateMobile-v1.0.N.apk`（tag：`mobile-v1.0.N`），開啟安裝。第一次要允許「安裝未知應用」。
2. 第一次開啟：輸入 YTmate 密碼（裝置名稱可以改）。之後這台裝置自動登入；可以在網頁的「📺 電視配對」頁取消（📱 圖示）。
3. 小米／紅米／小米平板建議：「更多 → 🔋 允許背景執行」，再到 設定 → 應用設定 → 應用管理 → YTmate →
   省電策略「無限制」、打開「自啟動」。背景播放、長時間錄音才不會被系統省電關掉。

## 功能
- **首頁**：最新同步大橫幅、▶ 繼續觀看（記住看到哪裡，跟電視共用）、🆕 最新同步、🎙️ 我的節目、所有頻道。
- **頻道**：搜尋頻道、頻道內搜尋影片、全部播放、隨機播放。
- **播放**（原生 ExoPlayer）：
  - 背景播放：鎖螢幕、切到別的 App 都繼續播；通知列、鎖定畫面、藍牙耳機都能控制；拔耳機自動暫停。
  - 右上角：🎧 只聽聲音（有 mp3 就改播 mp3、省流量）、倍速 0.75～2x、⏲ 睡眠定時、▣ 子母畫面（播影片時按 Home 也會自動變子母畫面）。
  - 字幕（中文／英文／關，設定在「更多」）、橫放全螢幕、每支影片多個版本（播不了自動換 480p／mp3）。
  - 頁面底部的迷你播放列：暫停、下一支、點一下回到播放畫面。
- **🎤 錄音**：
  - 開始前提示可錄時長（依手機剩餘空間，每小時約 14 MB）和電量，可以填標題、選類型（會議／上課／筆記）與語言。
  - 前景服務：鎖螢幕照錄，通知列有計時和「停止錄音」。
  - 每約 60 秒存一段，有網路就邊錄邊上傳；沒網路先存在手機，App 重開或網路恢復後自動補傳。
  - 全部傳完伺服器自動轉文字、AI 摘要，放進「🎤 錄音」頻道。
- **🕹️ 遙控**：開手機遙控頁，控制家裡的電視。
- **📥 稍後看**：貼連結，或在其他 App 按「分享 → YTmate」（YouTube、B 站、CNN、X）→ 下載到「📥 稍後看」頻道。
- **平板**：版面自動變寬（頻道一排 3～4 個、影片清單兩欄）。

## 檔案
- `MainActivity.kt`：WebView、密碼登記與自動登入、JS 橋接（window.YTmateApp）、分享連結。
- `PlayerHub.kt`／`PlaybackService.kt`／`PlayerActivity.kt`：播放核心、背景播放服務、播放畫面。
- `RecorderService.kt`：錄音（AAC 32 kbps ADTS）與邊錄邊上傳。
- `Net.kt`：設定與伺服器連線（cookie 過期自動用裝置金鑰重新登入）。
- 編譯：`.github/workflows/mobile.yml`（簽章跟電視版同一把）。
